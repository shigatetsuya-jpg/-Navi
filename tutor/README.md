# 完全個別オンライン指導 生徒募集サイト

LINE友だち追加をゴールにした1ページのランディングページです（静的サイト：HTML/CSS/JS のみ、ビルド不要）。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | ランディングページ本体 |
| `config.js` | **季節キャッチコピーの切り替え**・LINE URL（ここだけ書き換えればOK） |
| `style.css` / `main.js` | デザイン・動き |
| `tokushoho.html` | 特定商取引法に基づく表記 |
| `privacy.html` | プライバシーポリシー |
| `terms.html` | 受講規約（振替・キャンセル・解約・料金） |
| `img/line-qr.svg` | LINE友だち追加QRコード（https://lin.ee/PueA4XW） |
| `img/ogp.jpg` | SNS・LINEでシェアしたときの画像（1200×630） |

## キャッチコピーの切り替え

`config.js` の `season` を `"spring"`（春版）または `"allyear"`（通年版）に変えるだけです。
新しい季節を足すときは `catchCopies` に項目を追加します。

## 公開前チェックリスト

画面上で黄色く表示される **【要記入】** をすべて書き換えてください（`grep -n 要記入 *.html` で一覧できます）。

- [x] 対応科目・授業時間/頻度・事業者名・連絡先・通信トラブル時の扱い
- [x] 契約期間（1ヶ月単位・自動更新）・支払方法（銀行振込・前月末前払い・手数料はお客様負担）・振替/解約/返金のルール
- [ ] 料金表の「入会金・教材費：なし」が実態どおりか確認（`index.html` / `tokushoho.html` / `terms.html`）
- [ ] 事例Aに具体的な数値を載せる場合は、記録が残っている事実かつ本人・保護者の同意を得たもののみ
- [ ] 講師写真を載せる場合は `index.html` の講師アバター部分を `<img>` に差し替え（WebP推奨）
- [ ] `index.html` の `og:url` / `og:image` を公開URLの絶対パスに書き換え
- [ ] 複数月契約（2ヶ月超かつ総額5万円超）にする場合は、特定継続的役務提供の法定書面を用意
- [ ] アクセス解析を入れる場合は `privacy.html` の「6. アクセス解析について」を書き換え

※法律の専門家による確認ではありません。最終判断は必要に応じて消費生活センターや専門家にご確認ください。

## 公開方法（例）

- **GitHub Pages**：リポジトリの Settings → Pages で公開し、`/tutor/` を開く
- **Render Static Site / Vercel**：Publish directory（Root Directory）を `tutor` に設定
