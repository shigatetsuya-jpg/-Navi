# 試用前のデータ取扱説明・確認事項（未公開案）

関連：S1/T03。現在のコードを基にした説明案であり、確定した利用規約や法令適合の保証ではない。運営者・問い合わせ先・保存期間・外部サービスの設定を確定し、公開内容を承認してからサイトへ掲載する。

## 利用者へ伝える内容の案
新歓ナビは、サークル等の情報検索、イベント申込、団体による申込対応のために情報を扱います。閲覧・検索は登録なしで利用できます。

| 情報 | 使う目的 | 閲覧できる相手 |
|---|---|---|
| 氏名・メール・アカウント区分・大学・学年 | ログインと申込の管理、必要な連絡 | 本人と運営。団体の申込画面には氏名・大学・学年を表示するが、メールは表示しない |
| パスワードのハッシュ・認証セッション | 本人確認 | サーバーで管理。パスワードそのものを保存しない |
| 団体情報・担当関係 | 掲載の確認、イベント運営 | 公開・確認済みの項目は一般公開。申請者のメール等は運営が確認 |
| イベント・申込内容・任意メッセージ・状態 | 参加受付と判断、定員管理 | 申込者本人、担当団体、運営。学生向けに案内する共有範囲と管理者APIの実装を公開前に再照合する |
| お気に入り・時間割 | 自分に合う団体の検索 | このブラウザのlocalStorage。現在は他端末へ同期しない |
| 確認用トークン・通知キュー | メール所有確認と通知 | サーバーで管理。通常通知に学生の氏名・申込本文を入れない |

実際の本番構成はRenderで動作します。メール送信はResendを使う開発コードがありますが、本番での設定・送信・説明と承認は未完了です。外部解析サービスの追加送信は行っていません。

## 試用前に確定する項目
- 運営者の表示名と問い合わせ先。学校公認や大学による運営と誤認させない。
- 各データの保存期間、退会・掲載停止・訂正・削除依頼の受付方法。
- 団体の担当者が変わるときの本人確認・権限移管、アカウント復旧の手順。
- メール送信の有無と相手、送信元、確認・再送・配信失敗の対応。
- Render等での保管・ログ・バックアップの扱い。ディスク内コピーと外部退避の範囲。

## 現行コードで確認できる保持動作
ログインCookieと認証セッションの有効期間は7日。メール確認リンクは24時間。期限が切れることとDBから自動削除されることは別であり、期限切れレコードの掃除は未確認。送信済み／最終失敗したメールのpayloadは消去するが、宛先・履歴がすべて消えるわけではない。

管理者による利用者削除APIは本人のアカウント・申込等を削除する。団体アカウントだけを削除しても公開団体の情報自体を常に削除するわけではなく、他管理者がいない団体は非公開化・受付終了する。メール履歴・バックアップ・ログは別の保持方針が必要。削除の実行は対象と影響を確認してから行う。

## 利用条件として説明することの案
掲載情報の確認日・出典と、団体の公式情報を確認する方法を示す。サイト上の申込承認と、入会・参加費支払い・実参加を区別する。大学公認表示や掲載を運営の推薦・学校の保証と取り違えない説明を入れる。
禁止行為・掲載訂正・停止・問い合わせ対応・料金がある場合の条件は、実際の運営方針を決めたうえで文案を確定する。未決定の免責、料金、保存期間を事実として公開しない。
