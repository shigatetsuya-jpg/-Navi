- `npm run test:browser`：別セッションの運営・団体・学生で登録→メール確認→団体申請→承認→イベント→申込→判断→取消→バックアップ復元を検証。団体下書きにパスワードが含まれないことも確認。
- `test/browser/comparison.mjs`：390px/1280pxで比較の2〜4団体制限、選択解除、差分表示、表のスクロールを検証。
