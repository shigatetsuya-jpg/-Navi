# 使用交渉を始めるための判定

関連：S1/T02,T03,T04、S3/T10、S4/T13,T15。
ユーザーが試用版をある程度完成させた段階で団体への使用交渉を担当する。エージェントから交渉開始時点を明示する。現状は準備中。

| 項目 | 現在の状態 | 交渉開始の条件 |
|---|---|---|
| デモと説明 | 導入手順・FAQ・募集文案あり | 手元デモの主要操作を通し、使える機能と制限を1枚で説明できる |
| 学生・団体・運営の操作 | 独立した3役のブラウザで一連の操作を完了（ローカル） | 同一の試用構成で登録・団体確認・イベント・申込・判断・取消を通す |
| 通知 | 開発環境の代替送信で検証 | 実メールを使うなら送信元・宛先・送信承認・到達確認。通知なしの限定試用なら代わりの確認手順を明示し合意する |
| データ保全 | バックアップから別プロセスのアプリ起動と状態復元を確認（ローカル） | 試用環境の保管先・復元確認・取扱担当を確定 |
| 連絡先・利用条件 | 未確定 | 運営者の連絡先と個人情報の用途・共有先・削除窓口を説明できる |
| 初期情報 | 本番公開団体0件 | 合成データのデモと実団体掲載を区別。団体の同意と公開承認後に掲載 |
| 交渉資料 | 未送信の文案あり | 対象・試用期間・料金・責任範囲・参加依頼内容を確定 |

すべてを満たすか、未提供機能を除いた限定試用の範囲にユーザーが合意したときに「使用交渉を始めてよい段階」と報告する。実メール送信、外部公開、掲載データ追加、契約等をこの判定だけで実行しない。
