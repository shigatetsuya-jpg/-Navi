# 団体向け導入手順・FAQ・募集文案

関連：G0 → S4 → S4.M1 → S4.M1.I1 → T13。運営者用の準備資料。まだ外部配布・送信しない。

## 最初のイベント受付まで
1. 新歓ナビの「団体登録」を選ぶ。氏名・メール・12文字以上のパスワード、団体名・大学・キャンパスを入力する。カテゴリ・団体紹介は可能な範囲で追加する。
2. 団体画面を開いて登録した団体を確認する。運営による確認前でもイベントを下書きにできる。
3. 体験会の名前、日時、場所、内容、定員、申込締切を入力し下書き保存する。日時や場所が未確定なら公開受付を始めず、運営と確認する。
4. 運営が掲載情報と担当者を確認する。運営による確認・公開と、今回のプロジェクト責任者による公開承認が完了してから、イベントを「受付中」にする。
5. 学生が申し込むと団体画面の一覧に表示される。承認・見送りを選び、対応状況を学生がマイページで確認できるようにする。
6. 定員に達するとキャンセル待ちになる。空きが出ると待機順に受付中へ繰り上がる。受付中と承認済みが枠を使う。
7. 体験会が終わったら受付状態と掲載情報を見直す。実際の参加人数はサイト上の承認件数と別に確認する。

## FAQ
- 学生は登録しないと検索できない？ → 閲覧・検索・比較は登録不要。申込には個人登録が必要。
- 掲載は大学の公認を意味する？ → 意味しない。大学公認の表示には別の根拠が必要。
- 学生のメールアドレスが見える？ → 団体の申込画面には返さない。氏名・大学・学年・任意メッセージを担当団体に表示する。
- メールで申込に気づける？ → 通知は開発中。本番の実送信確認が完了するまでは団体画面で確認する。検証後に有効化する場合もメール所有確認が必要。
- 同じ学生が何回も申し込める？ → 同じイベントへの有効な重複申込は防ぐ。取消・見送り後の再申込は可能。
- 料金は？ → 有料プランは検討段階。料金・提供条件はまだ決定していない。無料・有料の提供を契約として約束する文面は承認後に確定する。
- 情報を訂正したい／アカウントを失ったら？ → 運営窓口で本人性を確認して対応する。窓口アドレスと復旧手順は公開前に確定する。
