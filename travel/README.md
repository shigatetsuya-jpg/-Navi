# たびナビ（観光プランナー）デモ版

仕様草案「観光プランニングWebアプリ」のMVPを、**ビルド不要・APIキー不要**で動くかたちで実装したものです。
`travel/index.html` をブラウザで開くだけで動きます（PWA・オフラインキャッシュは http(s) で配信したときのみ有効）。

## 実装済み（仕様との対応）

| 仕様 | 実装内容 |
|---|---|
| 3.1 旅程の自動作成 | 目的地・出発地・日程・時刻・人数・予算・移動手段・興味ジャンル・ペース・除外条件（行列NG／雨天屋内／無料のみ）から日ごとの旅程を生成。営業時間・終了時刻・昼食/夕食・夜景の時間帯を考慮 |
| 　出力 | 日ごとのタイムライン（到着・滞在・移動時間）、地図上に日別ルート、差し替え・並べ替え・削除・追加・滞在時間変更（変更のたびに後続時刻を再計算） |
| 3.2 概算費用 | 交通費／宿泊費／食費／入場料／その他を幅で表示。各項目に「推定」「取得元」を明記。合計・1人あたり・予算との差 |
| 3.3 マップ | Leaflet（ピンチズーム・ドラッグ）、現在地表示と追従、方位（対応端末）、ピンタップ→シート内で詳細、3段階ボトムシート（スワイプ・フリック）、地図とリストの同期、徒歩/公共交通/車の所要時間比較、Googleマップへのワンタップ引き継ぎ。全画面遷移・広告なし |
| 3.4 現地モード | 「○分以内」「今営業中」「ジャンル」「予算」「混雑少なめ」「お気に入り」で絞り込み、地図/リスト切替、旅程への追加（最適な位置に挿入して後続時刻を再計算）、PWAキャッシュ |
| 3.5 混雑予測 | 第1段階相当：曜日・時間帯モデルによる3段階表示＋時間帯グラフ。データ時点・「目安」を必ず明記（スクレイピングなし） |
| 3.6 その他 | 旅程の保存（端末内）、共有リンク（URLに旅程を埋め込み、同行者が開いて編集可）、お気に入り |
| 7. 法務 | OSM帰属表示、予約は外部サイトへのリンクのみ、費用・混雑は目安である旨を表示、位置情報は端末内でのみ使用 |

## デモ版の制約と本番への置き換え

| デモ版 | 本番想定 |
|---|---|
| `spots.js` のサンプルデータ（京都26件・東京20件） | Google Places API（保存は規約の範囲内） |
| スコアリングによる旅程生成（`generate()`） | Places の候補 → LLM（JSONスキーマ固定）で選定・順序付け |
| 直線距離×迂回係数の移動時間（`travelMin()`） | Routes API で検証 |
| 相場からの費用推定（`estimateCost()`） | 乗換案内系API・宿泊予約サイトAPI |
| 混雑のサンプル推定（`crowdLevel()`） | 混雑予測API・オープンデータ → オプトインの匿名位置情報 |
| localStorage 保存・URL共有 | Supabase（Auth＋PostgreSQL）で保存・共同編集 |

位置情報が取得できない、または目的地から離れている場合は「デモ位置（都市の中心）」で表示します。

## ファイル

- `index.html` … 画面とスタイル
- `app.js` … 旅程生成・費用・地図・ボトムシートなどのロジック
- `spots.js` … サンプルのスポット・都市データ
- `sw.js` / `manifest.webmanifest` / `icon.svg` … PWA
