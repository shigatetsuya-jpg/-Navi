# 新歓ナビ 🌸

大学新入生向けの、サークル・部活を検索・比較できる「空きコマ × QOL」新歓特化型検索アプリです。
プログラミング知識ゼロでも使えるよう、**ブラウザだけで動く**構成になっています。

## 使い方（これだけ）

1. このフォルダをダウンロードする
2. **`index.html` をダブルクリック**して開く

以上です。サーバーもインストールも不要です。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | メインサイト（検索・マイ時間割・カード/時間割表示・比較・詳細・申し込み） |
| `admin.html` | 管理者ダッシュボード（フッターの「🔑 管理者ページ」からも開けます） |
| `data.js` | サークルのテストデータ（17件）と保存まわりの共通処理 |

## 主な機能

### 🔍 検索（Indeed風トップ）
- 曜日・時限（1限〜5限・昼休み・放課後）・キャンパス・カテゴリ・フリーワードで検索
- キャンパスは **早稲田・戸山・西早稲田・所沢** の4つ
- カテゴリは大分類（体育会・文化系・学術系・その他）→「細かく絞る」で
  バスケットボール・軽音などのジャンルまで絞り込み可能（使う細かさは利用者が選べます）

### 🗓️ マイ時間割（空きコマ検索）
- **最初はすべて「空きコマ」**。授業があるコマをタップすると「✕」になります
- 「この時間割で絞り込む」をONにすると、空きコマに活動があるサークルだけ表示
- 設定はブラウザに保存されるので、次回開いたときもそのまま

### 📋 一覧・比較
- カード表示（サークル名・カテゴリ・一言アピール・タグ・活動頻度）
- 時間割表示（どのコマにどのサークルがあるか一望）
- 「比較」チェックで最大3件まで、同ジャンルのサークルを横並び比較

### 📄 詳細ページ（ポップアップ）
- 活動スケジュール・活動費用・YouTube紹介動画の埋め込み枠・OB/OG進路実績・クチコミ
- 目立つ色の「体験申し込み（話を聞いてみる）」ボタン → 申し込みフォーム

### 📮 サークル掲載申請
- 必須は5項目だけ（サークル名・カテゴリ・キャンパス・活動コマ・連絡先メール）
- 任意項目はあとから追記OK。申請は管理者の承認後に公開されます

### 🔑 管理者ダッシュボード（`admin.html`）
- デモ用パスワード: **`admin2026`**
- 掲載申請の承認／却下
- 公開中サークルの編集（即サイトに反映）
- 不適切なレビューの削除
- 体験申し込みの一覧確認

## データについて（デモモード）

現在はテスト用の架空データ17件入りです。申請・編集・申し込みなどの変更は
ブラウザの `localStorage` に保存されます（他の人には共有されません）。

本番運用時は、Supabase（データベース＋認証）に接続して
「本物のデータベース・承認フロー・管理者認証」に置き換える想定です。
